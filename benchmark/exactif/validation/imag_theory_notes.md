# 虚轴严格 IF：integrate 的算符迹结构（理论笔记，2026-11-08）

状态：管线配方已机器精度闭环（`imag_closure.jl` / `imag_general.jl`，N=2/o2 全绿）；
本文记录 τ2 泛函的解码与闭式识别的进展/障碍，供后续理论工作接续。

## 1. τ2 泛函（integrate 的收缩语义）— 已完全测定

黑盒测量（`imag_trace_oracle.jl`，1024 次 pair-注入 + Möbius，`imag_tau2.csv`）：
`Z(S, I) = Σ_{a,b} S_a I_b τ2[(a,b)]`，τ2[(A_K, A_I)] = ±1 当且仅当
A_K ∪ A_I = 完整切片块的并，且每块的占据 ∈ {全K, 全I, 空, K/I 各一腿}；
"同切片 K 对 ∧ I 对"（4 腿 0）被禁；跨链"各取一腿"带 JW 型符号
（符号 = −1 当两根 K 腿同为 eta 或同为 bar）。

**算符迹解释**：imag-lattice 的 GMPS 是算符链（每切片一个 c/c† 对 = 时间副本），
`integrate(K, I)` = **两条算符链乘积的迹** Tr[ρ_K · ρ_I]，其中
- 每切片块的占据规则 = 同一生成器 θ² 幂零性（K 与 I 共享切片生成器 ⇒ 双占即灭）；
- 分裂情形的符号 = 把乘积重排到正则序的费米子交换符号；
- 跨切片"共享副本"结构给出 Tr[c] = 0 型相消（K={0,3} 单链迹为 0 等）。

这一解释把全部 17 个探针值（`imag_trace_probe.jl`）与 τ2 表统一起来。

## 2. 管线配方（已锁定，机器精度）

- **K 链**（自建，GTerm 注入）：门 exp(GTerm(bar_{g+1}, eta_{g+1}, e^{−τε_g}−1))
  + 杂质跨位分辨率 exp(GTerm(bar_{p+1}, eta_{p+2 环闭合}, −1))
  + BC exp(GTerm(bar_1, eta_k, −1))。
  ⚠ 库门张量（`_propagator_sparsegmps`+`mult!`）的多项式 ≠ (e^{−τε}−1) kernel 形式
  —— combo 判决：门用 ±e^{−τε} 时联合行不一致（0.43），(e^{−τε}−1) 系一致（1e-11）。
- **I 链** = 影响多项式 I*：联合 Z+n 行（h/g 均经 I 侧 Möbius 到单项式基；
  g_raw 经 `GTEMPO._mult_A(GTerm, mpsK)` 直测）min-norm 解 → 序贯消元
  exp(GTerm) 因子（任意偶腿）实现。ν_eff = I* 的 ∅ 系数。
- **读出**：n = 1 − g_end，g_raw/Z 经 `_mult_A` + integrate。
- 结果（N=2, order 2）：Z err ~1e-12、n err ~1e-13（εd 0..1.4）。

## 3. 结构发现

- **缝因子解耦**：I* = (1 + θ_{4}θ_{5}) ⊗ I' 精确成立（seam 切片自分辨率 +1，
  与 K 链 BC 无关地单独出现）。
- **I' 的 pair 投影** = 2×3 影响矩阵（行 = 切片 2,3 的 bar；列 = 切片 1,2,3 的 eta），
  切片 2/3 对称（Δ[2,3] = Δ[3,2]、Δ[2,2] = Δ[3,3]）——环平移不变性的体现。
- **3×3 exp-form 族（复规范）精确且唯一**（`imag_seamfit2.jl` 命中 9e-14；
  24 行联合约束 rank ≈ 11 复 ≥ 19 实参数 ⇒ 解唯一）。实行积族（F2）无解 ⇒
  多项式 I* 不是任何"实行积"的像。
- **h 行秩 = 3**（Z 的 εd 依赖 = x^0..x²，x = e^{−βεd}）；g 通道秩 7-8
  （n̂ 插入通道阶更高）——两者给联立系统的有效约束维数。

## 4. 闭式识别（未完成——障碍与路线）

u(k) 代数封闭性论证：双线性算符 c†ᵢcⱼ 封闭（[c†ᵢcⱼ, c†_kc_l] = δ_jk c†ᵢc_l − δ_il c†_kc_j），
故"分辨率/BC/门的逆 × 影响算符 Ω"都是 exp(bilinear)，I 链 = 单个 exp-form，
Δ̃ = log(ρ_K⁻¹ e^{Ω}) 应为矩阵公式。**但** `imag_matrixid.jl` 的直接矩阵公式扫描
（Ω ∈ {log(I±D̃), ±D̃} × ρ_K 序 × 对角相似变换）不命中（最优 94% 误差）。

障碍 = **img-弦规范**：多项式 → 算符像的映射带 JW 型弦（跨副本），弦使
"多项式 exp-form 的系数矩阵"与"算符 bilinear 矩阵"之间差一个非对角的
（Fock 基下对角、切片指标下非对角的）规范变换。数值唯一解 Δ̃ 含 O(1) 虚部
（如 [3,2] 虚部 2.918），正是弦相位的量级。

**路线**（下一轮）：①从探针值直接钉死 img 映射的弦（~5 个探针即可标定）；
②在弦规范下重推 ρ_K 的矩阵（弦 → Fock 基对角算符，切片指标下=多体对算符，
u(k) 论证在"弦规范矩阵"层面改用 2^k 维显式矩阵：8×8（N=2）—— 直接构造
ρ_K、Ω 的 8×8 矩阵，Δ̃ = log 回拉到 bilinear 块——数值上完全可行）；
③核对 exp-form(Δ̃) = I* 后写出闭式。

## 6. order-4 拟合路线验尸（2026-11-08，定量排除）

**背景**：closure 的联合行拟合（24 锚点，ridge=1e-13）残差 8e-5，曾被解读为
"I 槽多项式类在非均匀调度下不可达"的结构缺口。本轮五步解剖给出完全不同的结论。

1. **8e-5 是正则化伪影，不是结构缺口**（`imag_o4split.jl`/`imag_o4fit2.jl`）：
   - h-行单独拟合残差 2.06e-5 ≈ 联合残差 → 与 n 读出无关；
   - rhs 到行空间**真距离 5.6e-15（24 锚）/ 1.1e-14（36 锚）—— 系统机器精度一致**；
   - ridge 加在病态 A'A 上：σ≈3e-7 以下方向被 λ/(σ²+λ) 部分压制 → 8e-5。
   - 修复：截断 SVD min-norm（`IMAG_SVDTOL`，默认 1e-14）→ keep=17 残差 1.4e-10。
   - 病态源头：order-4 回文 ring 含负小时长门（τ=−0.0878），(e^{−τε}−1) 系数
     ~1e-2，高阶组合行衰减到 1e-12。
2. **均匀回归改进**：order-1 N=2 closure 在 SVD 求解器下 7.8e-14/1.7e-14（此前
   ~1e-12），解系数 ‖Ist‖∞=1.38、10 因子——良态。
3. **但 min-norm I* 网格外爆炸**（端到端）：锚点内 Z err 2.7e-8，网格外
   （εd=0.35..1.4）Z err ~0.7。旧 24 锚解外推大 εd：Z@12 预测 12788 vs 真值
   4.8（`imag_o4res.jl`）——拟合解含**指数增长伪方向**（增长率 ~0.79 ≈ 核倒数
   e^{+0.6756εd} 的量级）。大 εd 补测锚点（`IMAG_EDS` env，h3/g3 各 6 点，数据
   `imag_n2o4ma_{h,g}3.csv`）也无济于事：解系数反而爆到 9e6（ν_eff=5.7e6）。
4. **根因定性（`imag_o4phys.jl`）**：把行空间 34 个基方向的采样函数对"核单项式族"
   （x_a^p x_c^q，p≤2、q≤4 = 门乘积代数）分类——**0/34 个方向是纯物理的**。
   注入链表示的复合函数类 ⊃ 核的有理函数（增长/伪方向普遍混入每个方向）。
   有限锚点采样无法在有理函数类中钉住泛函（函数族维度 > 锚点数 → ker(采样)≠0，
   min-norm 的零空档分量 ≠ 真实 I* 的零空档分量）。**盲拟合路线原理性死亡。**
   均匀调度为何免疫：门时长恒等（order 1/2 的 ring 门全 = β/N，与 cells 无关）
   → 函数族坍缩到单变量 x 的多项式 → 维度 ≤ 锚点数 → 采样可钉住 → 全绿。
5. **isobatch 弱非均匀 o2 数据法证**（`n1o2mnuniA`，调度 env 未存档）：三种猜测
   调度（[0.55,0.45]²、cells=1/ring=[0.55,0.45]、cells=[0.55,0.45]/ring=[0.5,0.5]）
   的 honest rank-6 残差 2.1e-3/1.1e-4/2.8e-3——全部不一致，与 n1o4ma（rank-10
   + 1.9e-3）同类。**门非均匀 → 结构不一致**（order 2 亦然）；已无法进一步区分
   "猜测错调度"与"真不一致"，支线放弃。

**结论与剩余路线**：order-4（以及一切门非均匀调度）的 GMPS 管线闭包不能再走
测量+拟合路线。剩余路线 = 记忆中已规划的**算符层推导**：标定分次张量积嵌入
（JW 跨链弦，`imag_jwcalib.jl` 已定位缺失结构）→ 在 2^k 维算符代数里精确解
O_I（无函数类污染问题）→ 反演 img 构造 I-MPS → 端到端。基建已备：
`imag_imgderive.jl`（VEV 框架 9/9 探针）、`imag_jwcalib.jl`（mode-0 9/12，
失败探针全部是 K∧I 跨链 4-leg）、`imag_general.jl` 新求解器/env 支持。

**工程改动（本轮入 `imag_general.jl`）**：closure 的 ridge 求解 → 截断 SVD
（`IMAG_SVDTOL`，附真距离打印）；h/g 模式支持 `IMAG_EDS` 自定义 εd 网格
（写 `_h3`/`_g3`）；closure glob 加载全部行 CSV（按 εd 去重，大 εd 补测可混入）。
诊断脚本：`imag_o4split.jl`（通道分离）、`imag_o4fit2.jl`（σ 谱+真距离+env 调度）、
`imag_o4res.jl`（外推解剖）、`imag_o4phys.jl`（函数类分类）。

## 7. Plan D：探针族扩充——order-4 闭环达成（2026-11-09，~2e-7）

**转折点**：盲拟合的失败根源不是"无解"，而是**注入族 {inj(B)} 的复合张量空间秩不足**
（45+15 锚点下 honest rank ~25，Z 距 span 0.2；holdout 卡 0.4 不收敛）。
复合对 I-MPS **张量**线性（imag_jwcalib 已证加法性）→ 任何新探针 MPS 都是合法列。

**扩族**（`imag_probes.jl`）：
- (a) **随机符号模式注入** inj±(B, σ)，σ ∈ {±1}^{pairs(B)}（种子 20261109）——
  span{inj(B)} 之外的新张量方向。仅此一族即把 holdout 从 0.4 压到 2.2e-7！
- (b) mult! 乘积探针 mult(inj(B1), inj(B2))。
- (c) inj 族的插入通道行（g 通道：composite(mpsK_end, probe)）。

**联合拟合**（`imag_dfit.jl`）：设计 = 41 锚点 × (8192 inj + 8192 s [+ 8132 p])
列 × 2 行族（h 行 rhs=Z 锚；g 约束行 vend − (1−n)hz = 0）。列归一化（压 σ1 动态
范围）+ 截断 SVD min-norm。holdout = {0.35, 0.7, 1.05, 1.4} 双判决。

**结果 v2（机器精度，2026-11-09 深夜补遗——两个决定性修复）**：
- **修复 1：相对行加权**（w_i = 1/|rhs_i|）。绝对残差最小化下，负 εd 大行
  （|Z|~数百）完全支配拟合，O(1) 物理区被淹没——这是 3e-8"残差地板"和
  2e-7 holdout 的真正根源（**不是族张成极限**！）。相对加权后 Z-only 拟合
  res_anch 3e-8 → 3.1e-12，holdout 2e-7 → 3.7e-13。
- **修复 2：非齐次 vend 目标**（IMAG_NHOM=1）。g 约束行从齐次
  vend − (1−n)hz = 0 改为直接目标 vend = (1−n)·Z（rhs 非零、信息量足），
  权重 1/|(1−n)Z|。联合拟合（IMAG_GFIT=1，82 行 × 24576 列，rank ~23-34）：
  res_anch 1.15e-11，**holdout max 9.3e-12**。
- **端到端 ✅ PASS（机器精度）**（`imag_engage.jl`，23583 探针项实积分）：
  | εd | Z err | n err |
  |----|-------|-------|
  | 0.00 | 3.7e-12 | 6.0e-13 |
  | 0.35 | 7.6e-12 | 1.7e-12 |

  | 1.05 | 9.1e-12 | 3.5e-12 |

  **maxerr：Z 9.2e-12 / n 3.5e-12 —— order-4 与 orders 1/2 同级（1e-12 类）**。

**落地形态**：解为稠密探针组合（15391 项，无稀疏证书）→ 端到端 = **探针循环
